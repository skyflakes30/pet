# Pet

A little creature adventure made for Sky. Hatch a Moonseed, raise Wicklet into Glimveil and Noctilume, build a cozy cottage, and explore Moonveil Island.

The website runs directly from this repository on GitHub Pages. No sign-in or paid API is required to play. It is a solo adventure with on-device saves; export a backup before switching browsers or phones.

## Included
- Three regions, nine original wild creatures, turn-based battles, quests, furniture, and evolution.
- Root web files: the complete browser game, with no build required.
- [Pet-Source.zip](Pet-Source.zip): editable project including tests, Android app/home widget source, iOS app/WidgetKit source, and build instructions.

Native widgets require building, signing and installing their apps. Native builds and device tests have not been completed; no signed APK or IPA is included. Widgets share the installed app’s local save, not the website’s save automatically.

Open index.html locally, or serve this folder with a static web server. The app uses relative paths and supports the /pet/ GitHub Pages subpath. All creatures and artwork are original.
